# 뭉치랑 영상 보기 (1단계 웹앱)

파일 4개를 같은 폴더에 두고 정적 호스팅에 올리면 됩니다.

- index.html : 앱 전체 (화면, 기능, 디자인)
- manifest.webmanifest : 홈 화면에 앱처럼 설치하기 위한 정보
- icon-192.png, icon-512.png : 앱 아이콘

## 1. YouTube API 키 만들기
1. https://console.cloud.google.com 에서 새 프로젝트를 만듭니다.
2. "API 및 서비스 > 라이브러리"에서 YouTube Data API v3 를 사용 설정합니다.
3. "사용자 인증 정보 > 사용자 인증 정보 만들기 > API 키"로 키를 만듭니다.
4. 키 제한에서 "웹사이트"를 고르고 내 호스팅 주소(예: https://아이디.github.io/*)만 허용합니다.

## 2. GitHub Pages에 올리기
1. GitHub에 새 저장소를 만들고 4개 파일을 올립니다.
2. Settings > Pages 에서 Branch 를 main / (root) 로 저장합니다.
3. 잠시 뒤 https://아이디.github.io/저장소이름/ 주소가 생깁니다.

## 3. 갤럭시 탭에 설치
1. 탭의 Chrome 에서 위 주소를 엽니다.
2. 메뉴(⋮) > "홈 화면에 추가" 또는 "앱 설치"를 누릅니다.
3. 처음 실행하면 부모님 비밀번호 4자리와 API 키를 넣습니다.

## 노트북에서 만든 설정을 탭으로 옮기기
1. 노트북에서 부모님 설정 > 앱 설정 > "옮기기 코드 만들기"를 누릅니다. 코드가 자동으로 복사돼요.
2. 코드를 카카오톡 "나와의 채팅" 같은 곳에 붙여넣어 탭으로 보냅니다.
3. 탭에서 처음 실행하는 경우: 처음 설정 화면 아래쪽의 "다른 기기에서 만든 설정 가져오기"를 누르고 코드를 붙여넣습니다.
   이미 쓰고 있는 경우: 부모님 설정 > 앱 설정의 코드 칸에 붙여넣고 "붙여넣은 코드 가져오기"를 누릅니다.
- 영상 목록, 하루 규칙, 비밀번호, API 키가 옮겨지고, 탭에 있던 목록과 설정은 코드 내용으로 바뀝니다.
- 쿠키, 뭉치 키우기, 오늘 기록은 기기마다 따로라서 옮기지 않아요.
- 코드에 비밀번호와 API 키가 들어 있으니 나에게만 보내 주세요.

## 4. 아이가 앱 밖으로 못 나가게
- Family Link 로 YouTube 앱과 Chrome 을 막아 두세요.
- 설정 > 보안 및 개인정보 보호 > 기타 보안 설정 > "앱 고정"을 켜고 이 앱을 고정하세요.

## 알아둘 점
- 모든 기록(영상 목록, 시청 시간, 쿠키)은 탭 안에 저장됩니다. 브라우저 데이터를 지우면 사라져요.
- 쇼츠는 채널에서는 유튜브의 "쇼츠 제외 목록"을 쓰고, 검색·링크에서는 60초 이하 영상과 #shorts 제목을 거릅니다. 1~3분짜리 쇼츠가 가끔 섞일 수 있어요.
- 검색은 API 사용량을 많이 씁니다. 하루 무료 사용량 안에서 검색 수십 번 정도는 충분해요.
- 업로더가 퍼가기를 막은 영상은 재생되지 않고, 유튜브 광고는 그대로 나옵니다.
